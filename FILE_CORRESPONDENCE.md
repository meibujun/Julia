# File Correspondence: JWAS.jl to PyJWAS

This document outlines the mapping between key files in the original Julia JWAS.jl project and their corresponding modules or files in the Python PyJWAS translation. Note that the Python version may have a different internal structure, and logic from a single Julia file might be distributed across multiple Python files or consolidated.
