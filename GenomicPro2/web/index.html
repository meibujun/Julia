欢迎使用 GenomicPro2

高性能基因组预测与分析平台

集成多种先进的基因组分析方法，支持 GPU 加速、深度学习模型和交互式可视化。

🚀 GPU 加速

CUDA 支持，大规模数据集计算速度提升 10-50 倍

🧠 深度学习

Deep GBLUP 模型，捕捉复杂非线性遗传效应

📊 丰富可视化

Manhattan 图、QQ 图、PCA 图等多种交互式可视化

支持的预测模型
传统模型
  • GBLUP - 基因组最佳线性无偏预测
  • BayesR - 贝叶斯混合模型
  • BayesCπ - 贝叶斯变量选择
高级模型
  • RKHS - 再生核希尔伯特空间
  • Deep GBLUP - 深度学习模型
  • GPU-GBLUP - GPU 加速版本
群体结构分析
PCA - 主成分分析

检测群体分层，识别离群个体

ADMIXTURE - 混合分析

估计个体的祖先群体混合比例
