# GenomicPrediction.jl

欢迎使用 `GenomicPrediction.jl`，这是一个为基因组选择和预测设计的现代化、高性能 Julia 软件包。

## 软件目标

本软件包旨在提供一个集成了从经典统计遗传模型到最新深度学习方法的综合性平台。其核心优势包括：

- **高性能:** 利用 Julia 语言的即时编译 (JIT) 和并行计算能力，高效处理大规模数据集。
- **功能全面:** 实现 GBLUP、多种贝叶斯模型 ("Bayes alphabet")、ssGBLUP、LASSO，以及 FNN, CNN, Transformer, GNN 等深度学习模型。
- **易于使用:** 提供简洁统一的 API，并支持自动化超参数调优。
- **可扩展性:** 采用模块化设计，方便研究人员开发和集成新模型。
- **可复现性:** 遵循 FAIR 原则，内置模型和元数据管理功能。
